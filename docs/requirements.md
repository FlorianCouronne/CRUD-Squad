Functional requirement are grouped by user role and labeled using FR codes for clarity and grading
# This is for visitor Functional Requirements
 Code , Requirement , Description 
 **FR-V1** , View Home Page , Visitors must access the landing page displaying business hours, contact details, and introduction.
 **FR-V2** , View Service Menu , Visitors must view pricing tiers including Rs 500 Basic Wash, Rs 700 Paint Correction, Rs 1000 Ceramic Coating, and Rs 2200 Deep Cleaning.
 **FR-V3** , View Gallery , Visitors must access a visual gallery showcasing past car detailing work.
 **FR-V4** , Navigate UI , Visitors must be able to navigate between Home, Services, Gallery, and Book Online pages.

# This is for Customer Functional Requirements
 Code ,Requirement , Description 
 **FR-C1**  ,Create Account , Customers must register using email, username, phone number, and password. 
 **FR-C2**  ,Secure Login , Customers must log in securely using encrypted credentials. 
 **FR-C3**  ,Access Dashboard , Customers must access a personal dashboard showing profile details and booking history. 
 **FR-C4**  ,Book Service , Customers must select a service package, choose date/time, and submit a booking request. 
 **FR-C5**  ,Edit Profile , Customers must update contact information (email, phone number). 
 **FR-C6**  ,View Booking History,  Customers must view past and upcoming appointments.

# This is for Administrator Functional Requirements
 Code , Requirement , Description 
 **FR-A1** , Admin Login , Admins must access a secure backend login page. 
 **FR-A2** , Manage Prices , Admins must update service prices dynamically. 
 **FR-A3** , Manage Bookings , Admins must view, confirm, or cancel customer appointments. 
 **FR-A4** , Manage Services , Admins must add, edit, or remove service packages.
